# 她火视频工厂设计规格

日期：2026-06-14
项目：她火本地提示词中心 + 图片工作台
范围：新增本地「视频工厂」页面和受控自动化能力

## 背景

她火当前是本地桌面软件，核心能力是提示词中心、图片工作台、我的图库和 API 设置。新需求是在不改成画布、不接 Dreamina、不做在线 SaaS 的前提下，新增一个短视频生产工作台，用于制作火柴人/漫剧 IP 引流视频。

视频工厂的目标是把“找爆款、洗文案、拆分镜、生图、配音、剪辑、发布”收束到她火里。用户可以让「她火助手」自动执行，也可以在每一步看到并编辑文案、提示词、素材、标题、话题和封面。

产品内不使用 Codex 命名。所有用户可见能力统一叫「她火助手」或「她火自动化」。

## 阶段目标

### 阶段 1：单条视频一键成片

阶段 1 只追求单条视频完整链路稳定闭环：

1. 通过关键词自动搜索最近爆款，或粘贴抖音链接/上传本地视频。
2. 解析对标视频结构、字幕、音频和画面节奏。
3. 用 `claude-opus-4-6-thinking` 或用户配置的文本模型改写原创文案。
4. 选择视频套餐和目标时长。
5. 拆分镜并生成火柴人图片提示词。
6. 调用她火图片工作台能力生成火柴人图、封面图或展示图。
7. 导入或自动录制炎灵素材，穿插 AI 成品展示片段。
8. 生成配音、字幕和统一视频时间轴。
9. 默认用剪映引擎渲染，内置渲染兜底，DaVinci 引擎作为实验选项。
10. 生成标题、话题、简介、封面，用户确认后自动发布抖音。

阶段 1 不做批量矩阵生产，但必须为多账号、多 IP、任务队列和批量发布预留数据结构。

### 阶段 2：批量矩阵生产

阶段 2 在阶段 1 稳定后实现：

1. 关键词池、选题池和爆款候选池。
2. 一次生成多条脚本变体。
3. 批量生成火柴人图、封面和成品展示素材。
4. 批量渲染和失败重试。
5. 多抖音账号、多浏览器 Profile、多代理/IP 绑定。
6. 发布队列、发布间隔、账号健康记录和作品记录。
7. 同素材复用记录和参数变化，降低重复度。

## 产品结构

她火保留现有页面：

- 提示词中心
- 图片工作台
- 我的图库
- API 设置

新增并列入口：

- 视频工厂

视频工厂首页包含任务列表和新建任务入口。新建任务使用流程式界面，不做画布。流程如下：

1. 爆款来源
2. 脚本生成
3. 套餐和时长
4. 分镜和提示词
5. 素材生成和素材库
6. 配音和字幕
7. 剪辑预览和导出
8. 发布确认
9. 任务记录

每一步都可以由她火助手自动执行，也可以由用户手动编辑后继续。

## 视频套餐

阶段 1 内置三个视频套餐：

1. 火柴人表情包套餐
   - 默认推荐。
   - 火柴人吐槽/解说为主，穿插炎灵录屏和 AI 成品展示。
   - 画面提示词偏白底黑线、极简、表情包化。

2. 工具展示套餐
   - 炎灵操作录屏为主。
   - 强调一键生成、小白可做、流程跑通。

3. 成品大片套餐
   - 电影感 AI 成品展示为主。
   - 可单独成片，也可作为火柴人套餐的开头钩子或结尾转化片段。

用户创建任务时可以选择一个套餐，也可以组合多个套餐。

## 视频时长

阶段 1 支持四种目标时长：

- 30-45 秒
- 45-60 秒
- 60-90 秒
- 120 秒

她火助手根据时长控制文案字数、分镜数量、配音速度、素材穿插密度和转化口播长度。

## 爆款采集

阶段 1 同时支持自动入口和手动入口。

### 自动入口

用户输入关键词后，可以选择：

- 近 24-48 小时新爆款
- 近 7 天稳态爆款

自动入口优先使用用户授权的本机抖音登录态，也支持公开/开源接口作为备用。候选列表展示：

- 视频标题/描述
- 作者
- 发布时间
- 点赞、评论、收藏、分享等可获得指标
- 视频时长
- 来源账号
- 本地缓存状态

自动采集必须做成适配器。抖音页面、接口、风控或登录态变化导致自动采集失败时，不能阻塞后续成片链路。

### 手动入口

用户可以：

- 粘贴抖音链接
- 上传本地视频
- 选择历史采集视频

手动入口作为稳定兜底，保证视频工厂始终能从一个视频或一段文案开始工作。

## 抖音账号和发布

阶段 1 支持选择采集/发布账号，但不做矩阵队列。

每个抖音账号使用独立浏览器 Profile 保存登录态。阶段 2 扩展为账号环境：

- 抖音账号
- 浏览器 Profile
- 代理/IP 配置
- 发布策略
- 健康状态
- 发布记录

阶段 1 支持自动发布，但发布前必须有确认门：

1. 她火助手生成标题、话题、简介、封面。
2. 用户在确认弹窗中审核和修改。
3. 用户确认后，自动上传视频、填写内容、选择封面并发布。
4. 遇到验证码、登录过期、实名验证、风控提示或发布失败上限时暂停，让用户处理。

系统不偷取 cookie，不打印登录凭证，不绕过验证码或风控。

## 她火助手和受控工具层

视频工厂需要一个受控业务工具层。用户界面不叫 Codex，内部工具命名使用她火前缀：

- `ta_huo_video_list_tools`
- `ta_huo_video_call`

工具层只暴露业务动作，不给自动化逻辑任意文件系统能力。阶段 1 工具包括：

- 搜索爆款
- 下载或导入视频
- 解析视频
- 提取字幕和音频
- 生成爆款结构
- 改写脚本
- 拆分镜
- 生成火柴人提示词
- 调用图片工作台生图
- 导入炎灵素材
- 生成或导入配音
- 对齐字幕
- 生成统一视频时间轴
- 渲染视频
- 生成标题、话题、简介和封面
- 发布抖音
- 查询任务状态
- 暂停、恢复和取消任务

页面必须显示关键中间结果，并允许用户编辑：

- 完整文案脚本
- 分镜文本
- 每段分镜时间
- 火柴人图提示词
- 素材选择
- 配音文本
- 字幕文本
- 标题、话题、简介和封面

火柴人提示词编辑区保持简洁，只展示提示词框和必要操作，不展示无关元数据。

## 视频解析

解析模块输入为抖音视频、本地视频或手工文案。输出：

- 原视频基础信息
- 音频文件
- 语音转写文本
- 句子级时间轴
- 可选字词级时间轴
- 画面切点
- 镜头节奏摘要
- 爆款结构摘要
- 可复用钩子、论点、转化句

对标视频只能用于结构分析和原创改写，不能默认搬运原画面。需要使用原视频片段时，必须显式标记为用户导入素材。

## 脚本和分镜

脚本生成分两步：

1. 结构提取：从对标视频中提取开头钩子、痛点、演示、证明、转化、结尾。
2. 原创改写：按用户选择的套餐和时长生成新脚本。

分镜输出结构：

- 分镜 ID
- 开始时间
- 结束时间
- 口播文本
- 画面类型：火柴人、炎灵录屏、成品展示、字幕强调、转场
- 画面说明
- 图片提示词
- 负面提示词
- 素材引用
- 状态

分镜列表使用整洁紧凑的卡片或表格，不使用复杂画布。批量创建分镜时自动整理顺序和间距，让每个提示词都能看清并编辑。

## 火柴人图片生成

火柴人图片默认风格：

- 黑白火柴人简笔线稿
- 极简线条
- 头部含眼睛、眉毛、嘴巴
- 纯轮廓
- 无填色、无阴影
- 纯白背景
- 2D 平面构图
- 表情包式情绪表达

用户可以修改风格预设。图片生成复用她火图片工作台的 API 设置、模型选择、参考图和结果入库能力。

## 炎灵素材

阶段 1 采用两层策略：

1. 素材库优先
   - 用户手动导入炎灵操作录屏、特效片段和成品展示视频。
   - 她火助手根据分镜自动选择并穿插。

2. 自动录屏扩展
   - 软件可自动打开炎灵网页或软件。
   - 自动输入提示词、执行生成、录制指定片段并入库。
   - 遇到登录、验证码、生成失败或页面异常时暂停。

炎灵素材是教程链路中的核心展示素材。工具展示套餐必须优先使用炎灵，不默认使用其他工具录屏替代。

## 配音和字幕

阶段 1 配音优先稳定，不追求最高音质。支持：

- 本地/系统 TTS
- 可脚本化的类剪映文本朗读流程
- 用户导入音频

配音模块必须输出：

- 音频文件
- 句子级时间轴
- 可选字词级时间轴

如果 TTS 不返回时间戳，系统使用识别/对齐工具生成时间轴。字幕、火柴人图、炎灵片段和成品展示都按这个时间轴对齐。

## 剪辑引擎

视频工厂先生成统一 `VideoTimeline`，再交给剪辑引擎。阶段 1 支持三层引擎：

1. 剪映引擎，默认优先
   - 适合抖音短视频、字幕、贴纸、音效和模板导出。
   - 依赖剪映草稿和本机剪映环境。

2. 内置 FFmpeg/Remotion 渲染，稳定兜底
   - 不依赖外部剪辑软件。
   - 保证能导出 MP4。
   - 用于预览、失败兜底和批量自动化基础能力。

3. DaVinci 引擎，高级实验
   - 适合 90 秒、120 秒或更复杂的素材剪辑。
   - 不作为阶段 1 主链路。
   - 需要检测本机 DaVinci Resolve 安装和脚本能力。

同一个 `VideoTimeline` 应尽量可输出到不同引擎，避免业务流程被单一剪辑软件锁死。

## 素材和本地存储

大文件不放 IndexedDB。视频、音频、录屏、导出成片、渲染缓存保存在 `%APPDATA%\她火` 下的任务目录。

IndexedDB 只保存：

- 索引
- 缩略图
- 元数据
- 本地文件引用
- 任务状态
- 用户编辑记录

不得删除 `%APPDATA%\她火`。清理功能只能清理明确选择的缓存或任务产物，并需要用户确认。

## API 设置

她火不向用户内置私有 API Key。用户自己填写 API 地址和 Key。

设计要求：

- API 设置页支持文本模型、图片模型、视频/解析服务等分组配置。
- 可保存多个 API Profile。
- API Key 本地保存，不提交 git，不打印日志，不进入任务导出包。
- 默认配置可以提供 API 地址示例，但不能包含真实 Key。
- 激活码只控制功能权限，不替用户提供模型密钥。

## 激活码和授权

她火需要激活码系统。首次打开或授权过期时进入激活页。激活后保存本地授权凭证，后续启动和使用核心功能时校验。

授权能力：

- 在线激活码校验
- 必要时支持离线授权文件
- 设备绑定
- 授权有效期
- 功能套餐
- 授权状态页

功能开关建议：

- 基础提示词中心
- 图片工作台
- 视频工厂
- 自动发布
- 批量矩阵
- DaVinci 高级引擎

授权页显示套餐、到期时间和设备绑定状态，不显示密钥。

## 防逆向和加密边界

Electron 桌面软件不能承诺绝对不可逆向。设计目标是防普通复制、二次分发和直接改配置绕过，不与专业破解团队做无限对抗。

防护策略：

- 前端代码混淆和 asar 打包。
- 后端关键逻辑尽量放到本地编译服务，而不是全部放在 JS。
- 授权签名由服务端私钥签发，本地只放公钥验签。
- 本地授权文件加密保存，并绑定设备指纹。
- 核心工具调用前二次校验授权。
- 打包产物做完整性校验。
- 检测关键文件被篡改时拒绝运行核心功能。
- API Key 不写死在前端，不进入源码，不打印日志。

## 错误处理

关键失败必须可恢复：

- 抖音自动搜索失败：提示原因并允许手动链接/本地上传。
- 下载失败：允许重试或跳过采集。
- 解析失败：允许手动输入文案。
- 生图失败：允许重试、换模型或手动导入图片。
- 配音失败：允许换 TTS 或导入音频。
- 剪映导出失败：自动提示改用内置渲染。
- 自动发布失败：保留发布草稿和本地视频，允许重试。
- 验证码/风控：暂停任务并等待人工处理。

所有任务状态都要落盘，应用重启后可以恢复。

## 验收标准

阶段 1 完成时必须满足：

1. 她火有独立「视频工厂」入口。
2. 可以通过关键词搜索最近爆款候选。
3. 可以粘贴抖音链接或上传本地视频作为兜底。
4. 可以从对标视频或手工主题生成原创脚本。
5. 可以选择套餐和时长。
6. 可以生成并编辑分镜。
7. 每个火柴人分镜都能看到和编辑提示词。
8. 可以生成或导入火柴人图片。
9. 可以导入炎灵素材并自动穿插。
10. 可以生成配音并对齐字幕。
11. 可以生成统一 `VideoTimeline`。
12. 可以用至少一个引擎导出 MP4。
13. 剪映引擎失败时可以走内置渲染兜底。
14. 可以生成标题、话题、简介、封面。
15. 发布前有确认弹窗。
16. 可以自动发布到用户授权的抖音账号。
17. 验证码或风控提示会暂停，不硬闯。
18. 用户 API Key 由用户自填，本地保存，不提交和不打印。
19. 激活码可以控制视频工厂功能开关。
20. 重启应用后任务可恢复。

## 非目标

阶段 1 不做：

- 在线 SaaS 多租户后台。
- 直接迁移旧画布项目。
- Dreamina 接入。
- 无确认的大规模矩阵发布。
- 绕过抖音验证码或风控。
- 搬运原视频作为默认生产方式。
- 承诺 Electron 绝对不可逆向。
