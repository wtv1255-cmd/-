# 她火视频工厂二阶段设计规格

日期：2026-06-18
项目：她火本地提示词中心 / 视频工厂
范围：二阶段升级，重点是稳定可续跑的剪映草稿生产线

## 背景

视频工厂一阶段已经具备从任务、文案、分镜、火柴人生图、素材库、TTS 配置、时间线到发布草稿的基础链路。当前问题不在于“再堆更多按钮”，而在于把这些能力收束成一个安静、稳定、可全自动也可半自动的生产工作台。

二阶段目标不是默认导出 MP4，也不是直接替用户发布，而是让她火生成可编辑的剪映草稿和完整素材包。用户可以打开剪映继续精修、插入工具展示、真实漫剧片段或其他人工判断内容，再自行导出。

## 阶段目标

二阶段以“稳定剪映草稿生产线”为核心：

1. 验收当前安装包的真实能力，确认安装包、激活、API、火柴人生图、素材库、停止/继续、任务保存恢复可用。
2. 改造视频工厂 UI，从纵向堆叠改为顶部模块导航，保持现有主题颜色，不引入花哨视觉风格。
3. 支持全自动和半自动两种工作方式，用户可以从任意模块开始，例如直接粘贴文案并跳过视频解析。
4. 文案入口支持原文直用和文案改写，改写支持 A/B/C 三档，全自动默认 B 中改。
5. 每个 AI 模块独立配置主接口和备用接口，接口失败时自动切备用；没有备用时暂停并保留任务进度。
6. TTS 走本地路径配置，默认路径为 `D:\Index-TTS2_ZZDH`，不把 TTS 大模型打进安装包。
7. 根据脚本、分镜、TTS 音频、字幕、图片和外部素材生成统一时间线。
8. 默认生成剪映草稿和任务素材包，不默认合成 MP4。
9. 支持单分镜重生、补图、单图放大和恢复缩略图。
10. 增加断点续跑、失败隔离、停止/继续和失败项处理。
11. 完成升级后提供一份用户使用手册。

## 非目标

二阶段不默认实现以下内容：

- 不默认导出 MP4。MP4 预览可作为后续增强，但不是本阶段核心。
- 不做自动发布。发布、上传、对外发送必须有人工确认门。
- 不把 Index-TTS2 或其他大模型打包进安装包。
- 不强制 AI 替代剪映内的最终人工精修。
- 不改变当前软件主题颜色。
- 不把页面变成说明文档式界面，详细说明放到手册或高级面板。

## 用户体验原则

视频工厂需要安静、整洁、模块化。界面不再从上到下堆满所有功能，而是使用顶部模块导航：

1. 任务总览
2. 文案
3. 分镜
4. 素材
5. 配音字幕
6. 剪辑草稿
7. 设置

普通模式只显示必要操作和状态。复杂提示词、变量、约束、模型参数、失败日志和模板编辑放在高级展开区域。页面内不放大量注释文字，避免干扰生产。

## 工作模式

### 全自动

全自动模式从当前可用入口开始执行后续步骤。默认规则：

- 文案改写默认使用 B 中改。
- 生图失败自动重试并继续其他分镜。
- TTS、字幕、时间线和剪映草稿可以自动续跑。
- 失败项会进入任务记录和补救列表。
- 发布、覆盖已有草稿、删除素材、覆盖人工编辑结果必须人工确认。

### 半自动

半自动模式允许用户从任意模块开始：

- 直接粘贴文案，跳过视频解析。
- 只生成分镜，不生图。
- 只补某一张图。
- 只重新生成 TTS 或字幕。
- 只根据已有素材重新生成剪映草稿。

半自动操作不应破坏已成功素材，除非用户明确选择覆盖。

## 文案模块

文案模块提供两个通道。

### 原文直用

用户粘贴文案后，系统不调用文本模型改写，直接进入切句、分镜、TTS 和剪辑草稿。该通道适合用户已经写好口播稿的情况，也适合节省模型请求。

### 文案改写

文案改写支持三档强度：

- A 轻改：保留原结构，优化措辞、口播感和可读性。
- B 中改：保留主题，重排钩子、节奏、冲突、证明和转化。全自动默认使用 B。
- C 强改：只保留核心意思，重写成一条新文案。

改写强度是全局偏好。默认 B；用户手动改成 A 或 C 后，下次新任务默认沿用该选择。单个任务可临时改，不影响已经生成过的内容。

每档都有独立提示词模板。普通模式只选强度；高级模式可查看和编辑模板、变量、约束，并可恢复默认模板。

## 分镜模块

分镜根据最终文案切句生成，支持用户编辑：

- 口播文本
- 画面说明
- 生图提示词
- 反向提示词
- 时长
- 视觉类型
- 素材引用
- 是否锁定

分镜锁定后，AI 导演不能改写该分镜的口播、素材安排和时间段，只能在未锁定部分优化。

## 生图与素材模块

生图参数使用“预设优先，高级展开”的方式：

- 常用比例必须包括 9:16。
- 可配置模型、比例、张数、质量、风格提示、反向提示等高级参数。
- 当前任务可以停止和继续。
- 生图失败默认重试并继续队列。
- 某张图失败后可以单独补图。
- 某张图不满意后可以单独重生，不必全量重跑。
- 图片点击放大，再次点击或关闭后恢复缩略图。

素材库实时展示任务内图片、音频、字幕和草稿产物。文件按任务目录保存，文件名带序号，避免乱序。

### 外部素材

外部素材以人工标注为主。用户可以给素材标注：

- 工具展示
- 真实漫剧片段
- 情绪加强
- 开头钩子
- 结尾转化
- 产品证明

AI 只根据用户标注和分镜意图安排素材，不擅自判断素材用途。缺少匹配素材时，剪映草稿中放置清晰占位，提示用户在剪映中替换。

## TTS 与字幕

TTS 走本地路径配置：

- 默认路径：`D:\Index-TTS2_ZZDH`
- 用户可以修改路径。
- 安装包不得内置 TTS 大模型、checkpoint、venv 或 Index-TTS2 项目目录。
- 本机路径不可用时，TTS 模块暂停，不影响已生成的文案、分镜和图片。

音色采用“默认推荐 + 常用固定音色 + 高级选择”：

- 全局默认音色。
- 单任务临时音色。
- 常用几个音色来回切换。
- 高级区域可查看本地 TTS 可用音色或手动配置音色参数。

字幕生成规则：

- 先按脚本文案切句。
- 如果 TTS 返回时间戳，优先使用 TTS 时间戳。
- 如果 TTS 不返回时间戳，按句子长度和目标语速生成 fallback cue。
- 字幕 cue 进入统一时间线。

## 剪辑草稿模块

剪辑草稿模块合并 AI 导演和剪映草稿能力。

目标输出是可编辑剪映草稿，不是最终 MP4。她火负责组织：

- 火柴人图
- 外部素材
- TTS 配音
- 字幕
- 重点字幕
- 转场
- 缩放和轻微运动
- 占位片段
- 时间线顺序

AI 导演采用结构化剪辑计划，不做无约束自由发挥。计划必须包含：

- 每个分镜的时间段
- 使用的图片或素材
- 配音片段
- 字幕 cue
- 转场或缩放建议
- 是否占位
- 锁定状态

用户可以锁定：

- 分镜级内容
- 片段或轨道级内容

AI 不能修改锁定内容，只能优化未锁定部分。

默认每次生成新剪映草稿，草稿目录名包含任务 ID 和时间，不覆盖旧草稿。只有以下情况需要确认：

- 覆盖已有草稿
- 检测到该草稿已被用户手动编辑
- 删除旧素材
- 覆盖人工锁定内容

## API 主备接口

API 配置按模块独立管理，不使用一套全局接口硬套所有能力：

- 文案 / 分镜 AI
- 生图 AI
- 视频解析 AI
- 剪辑分析 / AI 导演
- 发布辅助

每个模块都有主接口和备用接口池。调用失败时：

1. 当前接口按模块策略重试。
2. 达到阈值后自动切换到下一个备用接口。
3. 备用接口成功后继续当前任务。
4. 所有接口失败时暂停任务并保留进度。

生图中转站波动是常态，失败后默认自动继续，不因单张失败中断整个队列。文案和分镜失败更容易影响全局，连续失败后暂停并提示用户处理。

## 断点续跑

每个任务有独立任务目录和快照。实时保存：

- 原始来源
- 最终文案
- 分镜
- 生图参数
- 图片素材
- 音频素材
- 字幕 cue
- 时间线
- 剪映草稿状态
- 失败记录

每个分镜、图片、TTS 段、字幕段和草稿步骤都有状态：

- 等待
- 运行中
- 成功
- 失败
- 已跳过
- 需人工处理

软件重启后按类型恢复：

- 生图、TTS、字幕、时间线、剪映草稿可自动续跑。
- 发布、上传、删除、覆盖人工编辑结果必须人工确认。
- 没有备用接口或本地 TTS 不可用时，任务暂停，不丢进度。

已成功的图片、音频和字幕不重做，只补失败项或用户明确选择重生的项。

## 激活码

一机一激活码写入产品设计，但不作为二阶段前半主线。推荐放在二阶段后半或三阶段：

- 机器码绑定激活码。
- 支持人工重置和重新发码。
- 先保留现有激活能力，不打断视频工厂主线。

## 验收标准

二阶段完成后至少满足：

1. 重新安装桌面安装包后可激活、填写 API 并创建视频任务。
2. 粘贴一条文案后，可以跳过视频解析，直接进入文案、分镜、生图、TTS 和剪辑草稿。
3. 文案改写支持原文直用、A/B/C 三档，全自动默认 B，全局偏好可保存。
4. 火柴人生图支持 9:16 参数、并发生成、停止、继续、失败自动处理、单图放大、单图重生和失败补图。
5. 素材库能实时看到任务图片、音频、字幕和草稿产物。
6. 本地 TTS 路径可配置，默认指向 `D:\Index-TTS2_ZZDH`，安装包不包含 TTS 大模型。
7. TTS 生成音频后，系统能生成字幕 cue，并和图片、素材组成统一时间线。
8. 生成可编辑剪映草稿，草稿和素材按任务目录保存，输出路径在界面显示。
9. 断线、接口失败、软件重启后，已完成素材不丢，可从失败项继续。
10. 发布类动作和覆盖人工编辑结果必须人工确认。
11. 视频工厂界面改为 7 个模块，页面安静、少说明文字、主题颜色不变。
12. 升级完成后提供用户使用手册。
