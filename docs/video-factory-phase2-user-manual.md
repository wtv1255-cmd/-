# 她火视频工厂二阶段用户手册

## 工作流概览

视频工厂按七个模块推进：任务总览、文案、分镜、素材、配音字幕、剪辑草稿、设置。普通模式只保留生产所需操作；高级参数、模板和故障信息放在展开区。

默认交付物是任务素材包和可编辑剪映草稿，不默认导出 MP4。用户在剪映中完成最终精修和导出。

## 全自动

全自动会从当前已有内容继续后续步骤。文案改写默认使用 B 中改；用户修改全局偏好后，新任务沿用新的默认档位。

可自动续跑的步骤包括生图、TTS、字幕、时间线和剪映草稿。发布、上传、删除、覆盖已有草稿、替换人工编辑结果必须人工确认。

## 半自动

半自动适合从任意模块开始：

- 直接粘贴文案，选择原文直通，跳过视频解析。
- 只生成分镜，不立即生图。
- 只补失败图片或单独重生某个分镜。
- 只生成 TTS、字幕或时间线。
- 用现有素材重新生成剪映草稿。

半自动操作不会重做已经成功的素材，除非用户明确选择重新生成或覆盖。

## 文案与改写

文案模块支持原文直通和 A/B/C 三档改写。

- A 轻改：保留结构，优化口播感。
- B 中改：重排钩子、节奏、证明和转化，全自动默认使用。
- C 强改：保留核心意思，重写成新脚本。

原文直通不会调用文本模型；改写才会使用文本模型。

## API 主备

文本和图片生成已接入运行时主备切换。用户可以为这两个模块配置主 API Profile 和备用 API Profile；出现可重试错误时，系统会切换备用接口。

视频解析和发布辅助目前是配置预留；本阶段没有把它们包装成已通过的外部 provider failover。没有可用备用接口时，任务暂停并保留已完成进度。API Key 不会写入任务日志或导出摘要。

AI director 当前是本地结构化草稿规划：它读取任务已有文案、分镜、素材和锁定状态生成剪映草稿计划。本阶段没有验证 AI director 的外部 provider failover。

## 生图、补图和素材

生图使用预设优先，常用比例包括 9:16、1:1 和 16:9。高级参数可设置尺寸、质量和风格强度。

每个分镜都有独立状态。失败后可以只补失败分镜；不满意时可以只重新生成当前分镜。点击缩略图可放大，再次点击恢复。

外部素材以人工标签为准，可标注工具展示、真实漫剧片段、情绪加强、开头钩子、结尾转化和产品证明。缺少匹配素材时，剪映草稿中会放入占位片段，提示在剪映中替换。

## TTS 和字幕

本地 TTS 默认路径是 `D:\Index-TTS2_ZZDH`。安装包不内置 Index-TTS2、checkpoint、venv 或大模型文件。

用户可以设置全局默认音色，也可以为当前任务临时选择音色。TTS 不可用时只暂停配音步骤，不清空文案、分镜、图片或已生成素材。手动音频模式可作为兜底。

字幕优先使用 TTS 返回的时间戳；没有时间戳时，按句子长度和目标语速生成 fallback cue。

## 剪映草稿

剪辑草稿模块根据统一时间线生成可编辑剪映草稿计划和任务素材包。草稿目录包含任务 ID 和时间戳；再次生成不会覆盖旧草稿。

AI director 计划会记录：

- 分镜和轨道时间段
- 使用的图片、外部素材、音频和字幕
- 占位片段
- 转场、缩放和重点字幕建议
- 分镜或轨道锁定状态

锁定的分镜或轨道不会被 AI 改写。检测到覆盖旧草稿、删除素材、发布上传或替换人工编辑结果时，需要用户确认。

## 断点续跑

任务快照保存来源、文案、分镜、生图参数、图片、音频、字幕、时间线、剪映草稿状态和失败记录。

每个生产步骤记录为等待、运行中、成功、失败、已跳过或需人工处理。软件重启后，安全步骤可从失败项继续；成功图片、音频、字幕和草稿不会重做。

如果所有备用 API 失败或本地 TTS 不可用，任务会暂停并显示原因。恢复后继续时，只处理失败或等待的步骤。

## 激活范围

当前版本保留现有激活能力。一机一激活码属于后续阶段设计，本阶段没有半实现机器码绑定或人工重置流程。
